An Amazon SNS Topic acts as a communication channel that distributes notifications to all subscribed endpoints.

## Step 1

Open **Amazon SNS**.

Navigate to

```
Topics
```

Click

```
Create topic
```

> **Figure 1**

>![Figure 1](/images/5-Workshop/5.9/create-topic/topics.png)

---

## Step 2

Configure

```
Type

Standard
```

Topic name

```
scada-fault-alerts
```

> **Figure 2**

>![Figure 1](/images/5-Workshop/5.9/create-topic/topic-name.png)

---

## Step 3

Click

```
Create topic
```

> **Figure 3**

>![Figure 1](/images/5-Workshop/5.9/create-topic/topic-created.png)

The SNS Topic is now ready to receive subscriptions.
