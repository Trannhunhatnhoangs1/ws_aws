Amazon SNS Topic đóng vai trò là kênh trung gian để phân phối thông báo đến các đối tượng đã đăng ký.

## Bước 1

Mở **Amazon SNS**.

Chọn

```
Topics
```

Nhấn

```
Create topic
```
