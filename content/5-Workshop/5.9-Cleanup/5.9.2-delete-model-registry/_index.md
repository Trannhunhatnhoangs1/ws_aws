To keep the workspace tidy and avoid metadata storage fees, you should delete unused Model Groups.

## Step 1: Navigate to Model Registry

In the **SageMaker Console**, navigate to **Models** → **Model Registry**.

## Step 2: Delete Model Versions

1. Find the **Model Package Group** of the SCADA project.
2. You need to click on that Group, select all model versions inside, and delete them first.

## Step 3: Delete Model Package Group

Finally, after deleting all versions, delete the Model Package Group itself.
